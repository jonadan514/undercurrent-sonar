## 개요 (`/`, `app/page.tsx`)

**목적**: 로그인 없이 들어왔을 때 "지금 사도 되는 시장인가"를 5초 안에 답하는 대시보드 홈.

**데이터 소스**: `/api/data/market-gate`, `/api/data/regime`, `/api/data/index-prediction`,
`/api/watchlist/candidates` (이번 주 워치리스트 후보 수) / KR 대응 엔드포인트.

**레이아웃 (데스크톱)**:
- 상단: 시장 배지 + 타이틀 + LIVE 배지
- KPI 카드 4개 (`KpiCard` 컴포넌트): 종합 판단(=마켓 게이트, GO/CAUTION/STOP), 체제 점수,
  이번 주 워치리스트 후보 수(순위 없음), 마켓 게이트
- 좌측 2/3: 핵심 체제 지표(센서별 그리드, 예: VIX/TREND/BREADTH/CREDIT/YIELD CURVE),
  지수 주요 지표(현재가/SMA200/변동성/모멘텀), 워치리스트 후보 카드(클릭 시 `/watchlist`로 이동)
- 우측 1/3: 종합 판단 카드(GO/CAUTION/STOP 큰 글씨), SPY/KOSPI 다음 주 방향 예측,
  `MiniPortfolio` (실거래 기반 미니 요약)
- 모바일: 별도 `MobileView` 컴포넌트로 세로 스택 레이아웃 (같은 데이터, 카드 3개 요약)

**설계 의도**: `sensorInfo()`가 센서 원점수를 4단계 한글 라벨(강세/중립/약세/위기 등)로
변환 — 원점수만 보여주면 직관적이지 않아서 텍스트 판정을 항상 같이 보여줌.

종목, 시장 체제 변화 등. `VERDICT_COLOR` 딕셔너리로 GO/CAUTION/STOP 색상 처리.

## 시장 체제 (`/regime`, `app/regime/page.tsx`)

**목적**: "지금이 risk_on/neutral/risk_off/crisis 중 어디인가"와 그 근거를 센서 단위로
분해해서 보여줌 — 개요 페이지보다 훨씬 상세한 버전.

**데이터 소스**: `/api/data/regime`, KR은 `/api/data/kr/regime`.

**레이아웃**:
- 체제 히어로 카드 (regimeColor로 강조된 큰 라벨)
- `REGIME_GUIDE` — 체제별 행동 지침 4단계 리스트 (✓ 신규 진입 가능 / ~ 선별적 진입 /
  ✗ 진입 자제 / ✗ 전면 보류)
- `STOP_LOSS` — 체제별 권장 손절선/전략 테이블
- 센서 메타(`US_SENSOR_META`/`KR_SENSOR_META`) — 각 센서의 가중치와 설명을 툴팁으로 제공

**설계 의도**: 가중치 주석에 "src/analyzers/kr_market_regime.py WEIGHTS와 일치해야 함"이라고
명시 — 프론트 표시값과 Python 계산 로직이 어긋나지 않도록 하는 수동 동기화 지점.

## 섹터 분석 (`/sector`, `app/sector/page.tsx`)

**목적**: 어떤 섹터가 지금 시장을 주도하는지(선행/후행), 경기 사이클상 어디에 있는지 파악.

**데이터 소스**: `/api/data/sector`, KR은 `/api/data/kr/sector`.

**레이아웃**:

  good/bad 판단이 아니라 국면을 나타내는 범주색이라 브랜드 앰버를 하나의 단계로 그대로 씀)
- 기간 탭(1d/1w/1m/3m)별 섹터 상대수익률 테이블 (`RetCell` — 양수 초록/음수 빨강)
- 선행/후행 섹터 하이라이트 목록

## 리스크 (`/risk`, `app/risk/page.tsx`)

**목적**: 실제 보유 종목(`my_trades` 기반) 기준으로 하루 최대 예상 손실(VaR), 섹터
집중도, 손절 임박 여부를 감시.

**데이터 소스**: `/api/data/risk`, `/api/data/risk-detail`.

**레이아웃**:
- 핵심 수치 카드: 현재 투자 비중 vs 권장 비중(체제별), 현금 비중, 하루 최대 예상 손실(VaR
  95%, 한도 1.5% 초과 시 경고)
- 알림 섹션 (있을 때만 노출)
- 보유 종목 현황 — 종목별 비중 바 + 손익률(양/음수 초록/빨강)
- 섹터 분산도 — 40% 이상 집중 시 경고(⚠) 배지

**설계 의도**: `investedPct > recPct + 10` 같은 "권장 대비 초과" 판정에는 반드시 실제
경고색(caution/bad)을, 정상 범위에는 실제 GOOD 초록을 써야 함 — 브랜드 앰버로 뭉뚱그리면
한눈에 위험 여부를 못 읽는 페이지라 이 부분만큼은 리테마 때 특히 주의해서 고쳤음.

## 워치리스트 (`/watchlist`, `app/watchlist/page.tsx`)

**목적**: (1) 재무 건전성 필터(트랩 필터) 통과 종목을 순위 없이(모멘텀 랭킹 없음) 전부
보여주고, (2) 사용자가 직접 담은 관심종목을 관리 — 메모, 종목별 정성 체크리스트, 네러티브
브리프. 예전엔 필터 통과 후 시장 적합 점수(품질+모멘텀+체제)로 시장별 상위 50종목만
추렸으나, 1~3년 펀더멘털 투자로 방향을 잡으며 랭킹 자체를 제거함.

**데이터 소스**: `/api/watchlist/candidates`(스크리닝 후보, `current_price` 필드로
스크리닝 시점 가격 포함), `/api/watchlist/my`(내 워치리스트 CRUD), `/api/watchlist/narrative`
(GPT 뉴스 기반 서사 분석, 종목당 캐시), `/api/watchlist/checklist`(종목별 정성 체크 5항목,
DB에 `stock_checklist` 테이블로 독립 저장 — 예전엔 전역 "투자 워크북" 탭이었으나 종목 상세
팝업 안으로 흡수됨).

**레이아웃**: 탭 2개(스크리닝 후보 / 내 워치리스트) + 필터 칩(시장, 체제) + 테이블(정렬은
market, symbol 알파벳 순 — 랭킹 아님). 행 클릭 시 `DetailModal` — 현재가(스크리닝
시점가), F-Score·부채비율·이자보상·현금흐름 지표 그리드, 체제 적합도, `StockTechPanel`
(가격 차트), 네러티브 브리프(장기 스토리·촉매·리스크 + 시장 단기 관심도 HOT/WARM/COLD는
보조 정보), 정성 체크리스트, 매수 이유 메모.

**설계 의도**: 이번 리테마 작업을 처음 검증한 페이지 — 나머지 9개 페이지의 팔레트/폰트/
모서리 규칙이 여기서 확정된 뒤 전체로 확대 적용됨.

## 포트폴리오 (`/portfolio`, `app/portfolio/page.tsx`)

**목적**: 실제 매매 기록(수동 입력) CRUD + 벤치마크(SPY/KOSPI) 대비 누적 성과 비교.

**데이터 소스**: `/api/trades`(CRUD), `/api/portfolio/prices`(현재가), `/api/portfolio/
performance`(누적 성과 시계열).

**레이아웃**: 탭 2개(매매 기록 / 성과 비교).
- 매매 기록: 매수/매도 폼 + 거래 리스트, 보유 종목은 평단가·현재가·손익률 자동 계산
- 성과 비교: "내 포트폴리오" vs 벤치마크 요약 카드(누적 수익률 %) + Recharts 라인 차트
  (기준점 100, 주간 종가 기준)

**설계 의도**: `/api/portfolio/performance`는 US·KR 종목이 섞인 계좌일 경우 주간 환율로
원화 환산 후 합산 — 안 그러면 달러 숫자와 원화 숫자를 그대로 더해 수익률이 크게 왜곡되는
버그가 있었음(수정 완료).

## 매수 체크 (`/workflow`, `app/workflow/page.tsx`)

**목적**: 실제로 매수 버튼을 누르기 전 마지막 관문 — 시장·종목 조건을 자동 판정 + 정성
판단 2개(수동) + 주문 계획 2개(반자동)를 확인하고, 통과하면 손실 한도 기반으로 몇 주를
살지 계산. 투자 기간을 "장기(1~3년)"로 두면 게이트·체제·리스크는 매수를 막지 않는 참고
경고로만 표시됨.

**데이터 소스**: `/api/watchlist/candidates`(워치리스트 후보 여부·Piotroski 매칭),
`/api/watchlist/narrative`(네러티브 브리프 존재 여부), `/api/watchlist/my`(내 워치리스트
칩 자동 노출), `/api/fx/usdkrw`(포지션 사이징 계산기의 원화→달러 자동 환산).

**레이아웃**:
- 티커 입력(내 워치리스트 종목은 칩으로 바로 클릭 가능) → 워치리스트 후보 자동 매칭 표시
- 체크리스트 (`CK_GROUPS`): 자동 검증(마켓 게이트·체제·리스크·워치리스트 후보 포함
  (재무 필터 통과)·Piotroski≥6·네러티브 브리프 확인), 사용자 판단(정성 검증·여유 자금,
  수동 클릭), 주문 계획(손절가·수량 입력). 선행섹터는 정보성으로 별도 표시되며 판정에는
  포함되지 않음
- 포지션 사이징 계산기: "총 투자 자금(₩)" 단일 입력 + 허용 손실 % → 실시간 환율로 미국
  종목이면 자동 환산 후 최대 매수 수량 산출 (Fixed Fraction 방식 + Kelly 참고치)

**설계 의도**: 이 페이지가 이번 세션에서 버그가 가장 많이 나온 곳 — (1) 원화/달러 컨텍스트
혼동, (2) "선행 섹터" 항목이 클릭은 안 되는데 판정에는 들어가 있던 UI/로직 불일치,
(3) STEP3 카드가 선행 섹터 미적용 상태를 사실과 다르게 표시하던 문제. 전부 실사용 중
발견되어 수정됨 — 이 페이지를 다시 만지면 "표시 문구가 실제 판정 로직과 일치하는지"를
가장 먼저 의심할 것.

## 가이드 (`/guide`, `/guide/detail`, `app/guide/page.tsx`, `app/guide/detail/page.tsx`)

(ML 랭킹/AI 빌더/다운로드 등 옛 탭 언급)와 맞지 않는 부분이 있음 — 실제 최신 설명은
`/guide` 페이지 자체와 이 문서를 참고할 것.
