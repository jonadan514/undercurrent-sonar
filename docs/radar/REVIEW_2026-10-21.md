## 4. 리뷰에서 본 것

### 작업 중 잡아 고친 것 (실제 데이터로 확인하다가)
1. **장외매수가 장내매수로 들어감** - 삼성전자 이재용 회장 7,667,100주(10/12)는 장외매수였다. DART 웹 뷰어가 UTF-8·EUC-KR을 섞어 보내
   "장내/장외"가 둘 다 '?'로 깨졌고, "매수(+)로 끝나면 넣기" 규칙이 통과시켰다. 깨지는 모양이 늘 같아("?옣?궡"=장내, "?옣?쇅"=장외)
   되돌려 읽고 **장내매수만** 넣는다. 못 가린 줄은 넣지 않고 로그에 남긴다.
2. **직함 글자 깨짐** - "10%?씠?긽주주" → 보고자·직함은 정형 API(elestock)에서, 깨진 직함은 "10% 이상 주주"로 다듬거나 버린다.
3. **한국 60일 채우기가 조용히 잘림** - DART 목록 함수가 4,000건(40쪽)에서 멈춘다. 2주 1,100건 안팎이라 매일 실행은 괜찮았지만 60일은 잘렸다 → 14일씩 나눠 받는다.
4. **웹 뷰어 절반이 빈 응답** - 처음엔 막힌 줄 알고 쉬기·멈추기를 넣었으나 실패 비율이 그대로. 실패 사유를 로그에 남겨 보니 **전부 SSLError**
   (간헐적 연결 끊김) → 2·4·6초 쉬고 4번까지 다시. 남은 103건 중 99건 읽음. 쉬기·멈추기(연속 5건 60초, 15건 중단)는 그대로 둔다.
5. **8-K 임원 변동의 사임/선임 낱말 구분이 거칠다** - 이사 선임 공시에 "사임·선임"이 붙음 → 붉은 주의 표시에서 뺐다. 낱말 구분은 이름표로만.
6. **테마 이벤트 목록에 "공급계약 공급계약 1.2조"** - 종류 이름과 요약 앞머리가 겹침 → 요약에서 앞머리를 뗀다.

### 리뷰에서 고친 것
1. **한국 지분공시 기간 첫날이 빠짐** - 14일씩 나누는 반복 조건이 `>`라 기간 첫날 하루가 빠졌다(매일 실행은 다음 날들이 겹쳐 실제 누락은 없었음) → `>=`.
2. **미국 내부자 수집이 실패하면 한국을 건너뜀** - 워크플로가 bash -e라 반복 첫 실패에서 끝났다 → 두 시장 다 돌리고 끝에서 실패로 알린다.
3. **개요 내부자 칸의 관심 밖 수가 잘린 목록 기준** - 브리핑 목록은 30종목에서 잘린다 → 시장별 전체 수(`split_by_market`)를 담아 그것을 센다.

### 확인했고 문제없는 것
- 원칙 1: 새 칸 어디에도 점수·등급 없음. 테마 이벤트는 세 축 화살표·라벨·정렬에 들어가지 않는다(옆 표시만). 순서는 관심 표시·산 사람 수·금액·건수처럼
  공시 숫자 그대로.
- 원칙 2: 내부자 금액은 공시 단가 × 주식 수, 8-K는 원문 첫머리를 번역·요약 없이, 한국 공시는 파싱 값. GPT 총평 입력(`compact`)엔 새 칸이 들어가지 않는다.
- 원칙 3: 트랩 필터 기준값 손대지 않음 - 관심 밖 새 이름은 기존 판정(`watchlist_screening_results`)을 읽기만.
- 원칙 4: 관심 밖 종목 재무는 통과·탈락·데이터부족 3분류, 판정이 없으면 "미확인"(탈락으로 단정 안 함).
- 원칙 5: `insider_trades`·`insider_filings_seen`·`us_8k_filings`는 INSERT OR IGNORE, `theme_events`는 실행마다 새 줄(computed_at 키).
- 보안: SEC 연락처는 Secrets(`SEC_USER_AGENT`)에만, 코드·로그에 없음. 새 API 4개는 모두 매개변수 SQL.
- 못 읽은 공시는 "본 것"으로 남기지 않아 다음 실행에서 다시 읽는다(한국 내부자). 8-K·Form 4 호출 실패도 다음 실행에서 다시.

### 남겨둔 것 (알려진 한계)
1. **Form 4 공동 보고** - 보고자가 여럿인 Form 4는 이름을 " / "로 이어 한 사람으로 센다 → "산 사람 수"가 적게 나올 수 있다.
2. **8-K 원문 첫머리 자르기** - 다음 항목·"Signature(s)" 낱말에서 끊는다. 본문에 "signature"가 나오면 일찍 끊길 수 있다(발췌만 짧아짐).
3. **한국 내부자는 DART 웹 뷰어(공식 API 아님)에 기댄다** - 화면 구조가 바뀌면 깨진다. 전부 못 읽으면 실패 알림이 온다.
4. **한국 공급계약 공시는 흔하다** - 테마 이벤트 건수가 한국에서 많이 나온다(인프라 건설 소속 13개 중 12개사). 테마끼리 비교보다 같은 테마의 주별 변화로 볼 것.
5. **관심 종목에 생긴 일**은 아래 칸 목록(각 30건, 실적 반전 새로 10개)에서 모은다 - 잘린 줄은 못 모은다. 관심 표시를 먼저 담는 칸이 대부분이라 드묾.
6. **미국 새 이름 범위는 S&P 500·400** - 소형주(S&P 600)는 아직 없다.
7. 새 칸의 화면 확인은 가짜 데이터 - 실제는 10/26 브리핑(새 칸들), 테마 레이더(지금 바로)로 사용자 확인 대기.
