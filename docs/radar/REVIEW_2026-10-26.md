- 13F 종목 비중을 막대·원형으로 → 100% 가로 막대(원형보다 길이 비교가 정확).

## 3. 13F 실제 데이터 점검에서 고친 것 (첫 실행 → 수정 → 재실행)

1. **가치 단위**: 바우포스트·듀케인은 2023년 뒤에도 천 달러 단위로 신고(주당 가치 0.1~0.5) → 주식 줄 주당 가치 중앙값 < $1이면 비교할 때 ×1000.
   원본 줄(`inst_13f_rows`)은 그대로(원칙 5). `Report 13F`(읽기 전용)로 운용사별 표 합계·주당 가치를 보고 찾았다.
2. **채권 줄**: CUSIP 발행 번호에 글자가 있으면 채권 → `put_call='DEBT'`로 따로, 화면 주식 목록에서 빠짐.
3. **CUSIP만 바뀐 같은 회사**(엑슨모빌 본사 이전)가 '새로'+'전량 매도'로 보임 → 같은 분기 같은 회사명이면 합침.
4. **티커**: OpenFIGI 줄 단위 오류(무료 한도)로 25%가 빠졌고, 거래소 조건 없이 다시 물으면 해외 상장·채권 티커가 섞였다
   (`CPRXEUR`·`HO1`·`SMCI 7 06.01.29`) → 오류는 저장 않고 다시 묻기, 미국 거래소 주식만, 티커 모양 검사, 못 찾은 주식은 SEC 회사 목록 이름이 같으면 그 티커.
   남은 못 찾은 종목(대개 상장 폐지·피인수된 매도 종목)은 회사명으로.

## 4. 리뷰에서 찾아 고친 것 (a47edf3)

1. **종목 상세가 13F 전체를 읽음**: 미국 종목 상세가 열릴 때마다 `/api/investors?symbol=`가 최신 분기 전 운용사 수천 줄을 읽고 JS에서 걸렀다 → SQL에서 그 티커만.
2. **주식 종류가 다른 같은 회사를 합칠 수 있음**: 3의 합치기 규칙이 회사명만 봐서, 알파벳 A주를 다 팔고 C주를 새로 산 분기면 한 보유로 합쳐졌을 것
   → 회사명 + 주식 종류(titleOfClass)가 같을 때만. 테스트 추가, 받은 신고로 다시 계산(`--rebuild`).
3. **개요가 13F 전체 응답을 받음**: 카드 하나에 운용사별 목록·재무 판정 조회까지 → `?summary=1`이면 재무 판정 조회를 건너뛴다.
4. 그대로 둔 것: '여러 곳이 함께 산 종목'은 운용사마다 가장 최근 분기 기준이라 퍼싱스퀘어(아직 1분기)가 섞인다 - 화면에 "각자 가장 최근 분기 기준"으로 적었다.
   확신 매수 3%와 화면 구조 통일 뒤 칸 순서는 실제 데이터를 보고 조정.
