## 4. 리뷰에서 본 것

### 고친 것
1. **야후 외부 링크 티커 표기** - 점이 든 미국 티커(BRK.B)는 야후에서 BRK-B. 후보가 아닌 종목 안내의 Yahoo 링크가 404가 될 수 있었다 → 점을 하이픈으로.

### 확인했고 문제없는 것
- 종목 링크가 다른 링크·버튼 안에 들어간 곳이 없다(중첩 링크 없음). 표 행에 클릭이 걸린 곳은 링크가 전파를 막는다.
- 워치리스트 주소 읽기는 처음 불러온 뒤 한 번만 - 메모 저장 뒤 다시 불러와도 카드가 다시 열리지 않는다. 카드를 닫으면 주소에서 뺀다.
- 개요 "이번 주 변화"는 새로 계산하지 않고 워치리스트 API·최신 브리핑 값 그대로(원칙 2). 순위·점수 없음(원칙 1).
- "전환 중인 섹터"는 판정이 아니라 조건(3달·1달 부호 반대) 일치 목록 - 숫자를 그대로 보여준다.
- 브리핑 앵커: 최신 주는 짧은 이름(#earnings), 지난 주는 주차를 붙여 여러 주를 펼쳐도 겹치지 않는다.

### 작업 중 있었던 일
- 10/20 섹터 커밋을 올릴 때 다른 세션의 10/19 작업이 먼저 main에 있어 PROGRESS 파일만 겹쳤다 → 두 기록을 모두 살려 합침(코드 충돌 없음).
- 화면 확인용 가짜 데이터가 실제 API 형태와 달라(네러티브·차트 API) 처음에 화면이 깨져 보였다 - 실제 API는 실패 시 오류 상태를 돌려줘
  화면이 처리한다. 가짜 데이터 쪽을 고쳐 확인.

### 남겨둔 것 (알려진 한계)
1. 개요 "관찰 노트 회고" 수는 브리핑 시점 값 - 그 뒤 판단을 남겨도 다음 브리핑까지 숫자가 남는다.
2. 개요 "실적 반전 새로"는 브리핑이 10개까지만 담아, 잘린 주에는 시장별이 아니라 미·한 합계로 보인다.
3. 개요 → 워치리스트(`?new=1`·`?preset=`)는 워치리스트의 시장 필터를 바꾸지 않는다(전체로 열림).
4. 섹터 경기 사이클 계산은 백엔드에 남아 저장만 된다(화면·브리핑 미사용) - 지워도 되지만 이력 차원에서 둠.
5. 화면 확인은 모두 가짜 데이터 - 실제 데이터로는 사용자 확인 대기(10/21).
