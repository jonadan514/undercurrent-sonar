# 주간 브리핑 지표 후보 (나중에 추가)

2026-10-05 사용자 결정: 주간 브리핑 첫 부분에 지수 + 금리·환율(미 10년물, 원/달러)을 넣었다.
다른 지표는 **후보로만 정리해 두고 나중에 고른다.** 넣을 때 지킬 것:

- 숫자는 수집·계산된 값 그대로 (LLM이 만들지 않는다 - 원칙 2).
- 텔레그램은 지표 줄을 최대 2줄로. 더 넣고 싶으면 웹 '주간 브리핑'에만.
- 값이 없으면 그 지표만 빠지고 메시지는 그대로 간다 (지금 금리·환율 줄과 같은 방식).
- 비교는 브리핑과 같이 주 1회(월요일), 5거래일 전 대비.
